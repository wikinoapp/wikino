# ページを書く手順書

コマンドの一覧は [SKILL.md](SKILL.md) を参照する。
各コマンドの引数と出力の項目は、初めて使う前に `wikino <command> --help` で確かめる。

利用者がページを書くよう明示的に頼んだときだけ、この手順に従う。
ページの作成と更新はすぐに公開される。
公開の前に利用者が内容を確かめたいときや、トークンに下書きの権限しか無いときは、[draft-and-publish.md](draft-and-publish.md) の手順で下書きとして書く。

## 書く前に読む

- 更新するときは、対象のページを `wikino page get <番号> --md` で読む。出力の `wikino_etag` が読んだ版になる
- 作成するときは、同じトピックの近いページを読み、見出しの立て方・書き方・リンクの張り方を揃える
- 作成するトピックの番号は `wikino topic list` で確かめる
- 同じタイトルのページが既にあるかを `wikino page list --topic <番号> --title <タイトル>` で確かめる。あれば作成ではなく更新する

## リンクを張る

- Wikiリンクは、リンク先のページを `wikino page search` で探してから、そのタイトルどおりに書く
- 存在しないページへの投機的なリンクを張らない。Wikiリンクが存在しないページを指すと、そのタイトルで未公開のページが作られる
- 別のトピックのページは `[[トピック名/タイトル]]` で指す

書き込む前に `--dry-run` を付けて実行し、出力の `wikilinks` を確かめる。

- `resolution` が `new_page` のリンクは、書き込むと未公開のページとして作られる。意図したものでなければ、タイトルの誤りを直すか、リンクをやめる
- `topic_not_found` のリンクはリンクにならない。トピック名を `wikino topic list` で確かめる

## 本文の渡し方を選ぶ

本文をコマンドの引数に直接書かず、ファイルに書いてから渡す。
引用符・改行・`$` などがシェルで崩れるのを避けるためである。
Windowsでは、文字コードが変わることがあるため、本文をパイプで渡さずに必ずファイルで渡す。

### 新しいページを作る

本文をファイルに書き、`wikino page create --topic <番号> --title <タイトル> --body-file <ファイル>` で作成する。

### 一部だけを変える

追記や数か所の修正は、`--edits` で検索置換する。
本文の全体を送り直さないため、大きなページでも書き込む量が小さい。

- `old_str` は、今の本文と空白・改行まで完全に一致させる。`wikino page get <番号> --md` の出力から写す
- `old_str` が複数の箇所に一致すると失敗する。前後の行を含めて、1か所に決まる長さにする
- 末尾への追記は、最後の数行を `old_str` にし、`new_str` にその数行と追記する内容を書く
- `--edits` ではタイトルを変えられない

### 大きく書き直す

`wikino page get <番号> --md > page-<番号>.md` で書き出したファイルを編集し、`wikino page update <番号> --md-file page-<番号>.md` で書き戻す。

- frontmatterの `wikino_` で始まるキーは変えない (`wikino_title` だけは、タイトルを変えるときに書き換えてよい)
- 大きなページは、ファイルの全体をコンテキストに読み込まず、必要な部分だけを読んで編集する
- `--md-file` では版をファイルから読むため、`--if-match` を付けない

### タイトルだけを変える

`wikino page update <番号> --title <新しいタイトル> --if-match <etag>` で変える。
今のところ、他のページのWikiリンクは書き換わらない。
リンクしているページは `wikino page backlinks` で分かるので、必要なら利用者に伝える。

## 版を渡す

`--body-file` と `--title` で更新するときは、読んだ版を `--if-match` に渡す。
版は `wikino page get` の出力の `etag` (`--md` では `wikino_etag`) である。

終了コード6で失敗したら、読んだ後に他の人がページを変更している。
読み直して、他の人の変更を消さないように自分の変更を反映し直してから書き込む。
`--force` は、利用者が「上書きしてよい」と言ったときだけ使う。

## 添付ファイルの参照を保つ

本文の `/attachments/{ID}` の参照は、消したり書き換えたりしない。
CLIからは新しい添付ファイルを貼れないため、画像を足したいと頼まれたら、Web画面で貼るよう利用者に伝える。

## 書き込みの結果を確かめる

- 成功したら、出力の `url` を利用者に示す
- 標準エラーに、作られたリンク先 (未公開のページ) の一覧が出たら、利用者に伝える
- 通信の失敗などで結果が分からないときは、送り直す前に読み直して反映済みかを確かめる。ページの作成は冪等ではなく、送り直すと二重に作られることがある (作成のときは `wikino page list --topic <番号> --title <タイトル>` で確かめる)
