# ログインと認証のエラーの手順書

コマンドの一覧は [SKILL.md](SKILL.md) を参照する。
各コマンドの引数と出力の項目は、初めて使う前に `wikino <command> --help` で確かめる。

## 今の資格情報を確かめる

まず `wikino auth status` を実行する。
資格情報ごとに、接続先・スペース・メンバー・トークンのスコープ (`token.scopes`) と有効期限が出る。

- 資格情報が無ければ、「ログインする」へ進む
- 使いたいスペースの資格情報があるのに既定になっていなければ、コマンドに `--space` を付けるか、利用者の了承を得て `wikino auth switch <スペース>` で既定を切り替える
- 項目の `error` に理由が出ていれば、その `hint` に従う

環境変数 `WIKINO_TOKEN` にトークンが渡されているときは、保存した資格情報よりそれが優先される。
そのときにログインし直しても効かないため、トークンを替えるよう利用者に頼む。

## ログインする

ログインには、利用者がブラウザでWikinoの画面を開いて許可する操作が要る。
自分だけでは完了できないため、次のどちらかで利用者に操作してもらう。

### 利用者に端末で実行してもらう (推奨)

`wikino auth login <スペース>` を利用者の端末で実行してもらう。
ブラウザが開き、許可するとログインが終わる。

### 自分で実行して、URLとコードを利用者に伝える

`wikino auth login <スペース> --device` を実行すると、確認用のURLとコードが標準エラーに出る。
そのURLとコードを利用者に伝え、ブラウザで開いてコードを入力し、許可してもらう。
コマンドは許可されるまで待つ (コードの期限は10分)。
期限までに許可されなければ失敗するので、利用者の準備ができてから実行し直す。

### 個人アクセストークンを使う

利用者がスペース設定で発行した個人アクセストークンを渡してきたときは、トークンをファイルに書いてもらい、`wikino auth login <スペース> --with-token < <ファイル>` でログインする。
トークンをコマンドの引数や会話に書き写さない。

## 認証の失敗 (終了コード3)

- ログインしていない、トークンが無効か期限切れである
- `wikino auth status` で資格情報を確かめ、無ければ「ログインする」に従う。あってもトークンが無効なら、ログインし直してもらう

## 権限の不足 (終了コード4)

トークンのスコープか、メンバーの権限が足りない。
エラーのメッセージに、足りないスコープが書かれていることが多い。

- `wikino auth status` で `token.scopes` を確かめる
- 足りないスコープがあれば、そのスコープを付けてログインし直すよう利用者に頼む (`wikino auth login <スペース> --scopes <スコープ>`)
- スコープが足りているのに失敗するときは、メンバーの権限 (スペースやトピックでの役割) の問題である。スペースの管理者に相談するよう利用者に伝える

ページを書く権限が無いことは、利用者がわざと絞っていることがある。
権限を広げるよう勝手に求めず、下書き ([draft-and-publish.md](draft-and-publish.md)) で代わりに書けないかを先に考える。
