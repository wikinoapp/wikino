**問題点・改善提案**:

- **[@docs/README.md#仕様書]**: 仕様書の「採用しなかった方針」セクション（566-593行目）と「参考資料」セクション（600行目）に Datastar への参照が残っている

  仕様書は「現在のシステムの状態」と「なぜそうなっているか」を記述するドキュメントである。htmx に移行した現在、「採用しなかった方針」の理由説明が Datastar 固有の制約に基づいており、現在のシステム（htmx ベース）では理由が異なる可能性がある。

  1. 「PATCH エンドポイントを SSE に変更する」セクション（566-573行目）: Datastar の `@patch()` 属性に言及
  2. 「PATCH が `text/html` で保存時刻とリンク一覧を返す」セクション（583行目）: 「Datastar の SSE フラグメント更新パターン」に言及
  3. 「参考資料」セクション（600行目）: Datastar 公式サイトへのリンク

  **修正案**:
  - htmx に移行済みの現状に合わせて不採用理由を更新する。PATCH + GET 分離を維持している理由を htmx の観点で記述し直す
  - Datastar 固有の制約を理由に挙げている箇所は、現在の技術（htmx）での不採用理由に書き換える
  - 参考資料から Datastar 公式サイトのリンクを削除し、必要であれば htmx 公式サイトのリンクを追加する
